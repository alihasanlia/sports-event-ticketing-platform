Edit Ticket Not Available

The Backend does not currently provide an endpoint for editing tickets.

Available endpoints:
• GET /api/v1/tickets/{ticketId}/details - View ticket details
• GET /api/v1/tickets/user/{userId} - List user tickets

Not available:
• PUT /api/v1/tickets - Update ticket
• PATCH /api/v1/tickets/{ticketId} - Partial update ticket

If you need to update a ticket, please contact the development team to add this functionality to the backend.
